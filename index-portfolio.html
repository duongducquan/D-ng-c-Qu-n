Dự án

Website công nghệ

ReactJS, Vite, Node.js, REST API, MySQL

  • Đăng nhập và quản lý tài khoản.
  • Quản lý sản phẩm.
  • Chatbot AI hỗ trợ tin nhắn văn bản, hình ảnh, sản phẩm và giọng nói.
  • Tích hợp thanh toán và tối ưu SEO.

Hệ thống chat thời gian thực

Node.js, Express.js, Socket.IO, MySQL, Artillery

  • Chat nhiều phòng, đồng bộ tin nhắn, kết nối lại khi mất mạng.
  • Lưu tin nhắn, hình ảnh và thông tin người dùng vào MySQL.
  • Đang nghiên cứu và lên phương án kiểm thử tải từ 100 đến 1.000 kết nối đồng thời, đo RAM, CPU và băng thông.

Tìm kiếm địa điểm bằng bản đồ

OpenStreetMap, Nominatim, REST API, JSON

  • Tìm kiếm địa chỉ, chuyển địa chỉ thành tọa độ và ngược lại.
  • Tìm hiểu cách dữ liệu bản đồ đi từ API đến Backend rồi đến Frontend.

OpenStreetMap → Nominatim → API → Backend → Frontend

Đã học

  • JavaScript nâng cao: Promise, async/await, Event Loop.
  • ReactJS: Hooks, React Router, quản lý trạng thái.
  • Node.js / Express: middleware, xử lý lỗi.
  • MySQL: JOIN, Index, Transaction, tối ưu truy vấn.
  • Bảo mật: phân quyền và bảo vệ API.
  • Socket.IO: xác thực kết nối, xử lý tải.
  • Git và Docker: quản lý mã nguồn, đóng gói ứng dụng.
  • CI/CD và kiểm thử: tự động kiểm thử, triển khai, đo hiệu năng.
  • SEO kỹ thuật: SSR, Pre-rendering, lập chỉ mục.

Giới thiệu

👋 Xin chào mọi người! Mình là Dương Đức Quân, sinh năm 2006, hiện đang làm việc tại Công ty MID Việt Nam.

💻 Mình có niềm đam mê với lập trình, phát triển phần mềm và các công nghệ mới. Mình không ngừng học hỏi, nâng cao kỹ năng và xây dựng các dự án thực tế để phát triển bản thân trong lĩnh vực Công nghệ Thông tin.

🔥 Các lĩnh vực học tập và kỹ năng

  • 1. Lập trình Web Full Stack: Frontend (HTML, CSS, JavaScript, ReactJS); Backend (Node.js, Express.js, PHP, CodeIgniter); xây dựng API RESTful, tích hợp cơ sở dữ liệu và xác thực JWT; phát triển website bán hàng, website giới thiệu và hệ thống quản lý.
  • 2. Phát triển ứng dụng và hệ thống: quy trình phát triển phần mềm, xây dựng ứng dụng và tích hợp API, WebSocket / Socket.IO và giao tiếp thời gian thực, nghiên cứu AI, chatbot và tự động hóa.
  • 3. Công nghệ bản đồ và API: OpenStreetMap (OSM), Nominatim và Geocoding, tích hợp API bản đồ vào các dự án web.
  • 4. Cơ sở dữ liệu và Backend: MySQL và thiết kế cơ sở dữ liệu, xây dựng API và xác thực người dùng, tìm hiểu Docker, CI/CD và tối ưu hiệu suất hệ thống.
  • 5. Thiết kế và công cụ văn phòng: thiết kế giao diện website hiện đại, thiết kế PowerPoint chuyên nghiệp, xử lý dữ liệu và báo cáo bằng Excel.
